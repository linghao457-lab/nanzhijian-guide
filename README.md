# 南枝笺使用教程

分享网址：https://linghao457-lab.github.io/nanzhijian-guide/

适用南枝笺免费版1.0.0（19）。22章、176个操作步骤、25个常见问题；截图均为独立测试环境的虚构资料。教程无需登录，不连接真实业务数据，也不提供发码或授权服务。

此仓库只发布静态帮助网页。图片、字体、脚本均随站点提供；支持与隐私页面位于support/。

mirror-manifest.json固定各公开源文件及最终发布文件的SHA-256。标准GitHub Actions在部署前逐一验证，源文件有变化或抓取失败时不会发布部分教程。工作流仅在相关文件提交或手动运行时执行；不使用收费的大型运行器，不申请永久凭据。

维护时应先更新本地外置工作盘的教程源文件、检查真实界面与链接，再更新清单。旧站点以后可能停止，因此本地完整静态备份必须保留。此仓库中的下载地址只用于构建；读者访问的页面、图片与脚本均由GitHub Pages提供。
